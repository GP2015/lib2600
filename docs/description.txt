This document serves as a comprehensive description of the NTSC Atari 2600's functionality (as well as all the relevant peripheral devices' logic functionalities) and has been used as a reference for the development of the lib2600 emulator. Due to its comprehensive nature, this document is quite verbose and technical.

To avoid unnecessary repetition, all elements relating solely to electrical power transmission will be ignored, unless it affects the underlying logic in some meaningful way.

1. Console

1.1 Pinout

The base console has:
- 24-pin cartridge port
- two 9-pin controller ports
- three external logic switches
- two buttons
- RF signal output

It also features an external power switch, but this simply (dis)connects the console from its power source and is therefore ignored.

The three external logic switches are:
- TV Type (LOW for black & white output, HIGH for colour output)
- Left Difficulty (LOW for B, HIGH for A)
- Right Difficulty (LOW for B, HIGH for A)

The two external logic buttons are:
- Game Select (LOW when pressed, HIGH otherwise)
- Game Reset (LOW when pressed, HIGH otherwise)

Of the 24 pins in the cartridge port, the relevant ones are:
- 13 pins for the 13-bit address bus (intended to be output-only, but of course the cartridge can write to it anyway, resulting in bus contention)
- 8 pins for the 8-bit data bus (bi-directional)

Of the 9 pins in each controller port, 7 pins of each are used for transmitting data.

1.2 Chips

1.2.1 Overview

The console contains three different chips:
- 1.19 MHz MOS Technology 6507 microcontroller, acting as the CPU of the system
- MOS Technology 6532 RAM-I/O-Timer (RIOT), acting as the RAM, timer, and I/O handler of the system
- Television Interface Adapter (TIA), a custom chip acting as the audio & video processor of the system

1.2.3 RIOT

1.2.3.1 Overview

The RIOT chip has:
- input reset pin (/RES)
- input clock signal pin (PHI2)
- two input chip select pins (CS1 & /CS2)
- input RAM select pin (/RS)
- input read/write pin (R/W)
- 6-bit input address bus (A)
- 8-bit bi-directional data bus (DB)
- two 8-bit peripheral buses (PA & PB)
- output interrupt request pin (/IRQ)
